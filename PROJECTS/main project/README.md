# Main Project

DataSet : DoctorVists-DA.csv

About Dataset:

It consist of information about the number of visits, gender, age, income obtained by each individual, illness, reduce in activity due to illness, health, private, freepoor, freerepat, nchronic, lchronic
This data is used to find the number of duplicates,count of illness,count of illness based on gender,analyzes of income, reduced activity by individual due to illness,missing values,visualize the correlation between each attribute using heatmap,finding the correlation between income and no. of visits,gender wise illnes,insurance analysis,health status vs activity reduction heatmap ,Reduced activity by gender bar plot.
This data frame containing 5,190 observations on 12 variables.
